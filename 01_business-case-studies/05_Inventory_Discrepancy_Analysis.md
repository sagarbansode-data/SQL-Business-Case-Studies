# Inventory Discrepancy Analysis

## Module Overview

This module focuses on analysing inventory discrepancies to identify warehouse accuracy issues, high-risk inventory items and operational gaps.

The queries help evaluate inventory mismatches, variance trends and discrepancy patterns across warehouse operations.

---

## Business Objectives

This module answers questions such as:

- Which warehouses report the highest discrepancies?
- Which discrepancy types occur most frequently?
- Which inventory items have the highest variance?
- What is the average variance by discrepancy type?
- Which discrepancy records require immediate attention?

---

## Tables Used

- inventory_discrepancy_log
- inventory_item_master
- warehouses

---

## SQL Concepts Covered

- SELECT
- COUNT
- SUM
- AVG
- GROUP BY
- ORDER BY
- JOIN
- Subqueries

---

## Business Value

Discrepancy analysis supports inventory accuracy, warehouse auditing and operational risk management.

The insights generated from these queries help reduce stock mismatches, improve inventory control and strengthen warehouse performance.
